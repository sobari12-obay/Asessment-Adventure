# Peta Jalan Pengembangan — PSAS ADVENTURE

> Dokumen ringkas ini selaras dengan `/docs/DEVELOPMENT_ROADMAP.md`.

1. **Tahap 1 & 1A (Selesai)**: Arsitektur SDN Pekiringan, skema 20 koleksi Firestore, antarmuka utama ramah anak (Landing, EntryChoice, StudentLogin, TeacherLogin, Guide).
2. **Tahap 1B (Selesai)**: Dashboard Guru 8 menu, Dashboard Siswa pribadi, Peta 10 Dunia Nusantara (`AdventureWorldMap`), dan konfigurasi status terpisah (`worldStatusConfig.ts`).
3. **Tahap 1C (Selesai)**: Integrasi backend Node.js/TypeScript + Firebase Starter Tier (`verifyIdToken` + Firestore REST API), rate limiting login siswa, pencabutan token HMAC, pemisahan RBAC admin vs guru, `firestore.rules` ter-deploy, `storage.rules` diperketat, serta inisialisasi fondasi sekolah idempoten tanpa data fiktif.
4. **Tahap 1D (Selesai)**: Audit QA menyeluruh, penutupan celah endpoint validasi siswa & scoring, perbaikan rate limiter Wi-Fi kelas, sanitasi URL media/CSV, `ConfirmModal` konfirmasi hapus guru, lazy-loading bundel admin/XLSX, serta dokumentasi `QA_CHECKLIST.md`.
5. **Tahap 2 — Adventure Engine (Selesai)**: Gerbang Karakter wajib, Base Camp Penjelajah, Peta 10 Dunia + 30 Pos Ekspedisi, sistem XP & 10 jenjang level server-authoritative, 12 lencana otomatis, ledger `adventureEvents`, panel guru `Adventure Engine` (non-kompetitif), hook `ExamCompleted`, serta deploy `firestore.rules` Tahap 2.
6. **Tahap 3 — Assessment Engine (Selesai)**: Bank Soal terpusat, pembuatan & penerbitan paket ujian, 11 tipe soal, sesi pengerjaan siswa anti-leak kunci dengan pemulihan refresh F5, koreksi esai manual + rubrik, serta analitik hasil. (Kalender Jadwal PSAS otomatis & rapor semester lanjutan menunggu tahap polish sekolah).
7. **Tahap 4 — AI Question Import (Selesai)**: Wizard impor soal berbantuan AI (`.docx`, `.pdf` + scanned PDF, `.xlsx`, `.csv`, foto, kamera) via Gemini `gemini-4-hydrogen` server-side dengan penegakan kunci kosong (`BELUM_DIVERIFIKASI`), persetujuan eksplisit guru, deteksi duplikat, simpan idempoten, dan pembersihan temp otomatis.
8. **Tahap 5 — Finalisasi, Laporan, Analitik & Gamifikasi (Selesai)**: Pusat laporan terpadu guru (`ReportsAnalyticsHub`), pemisahan nilai resmi vs latihan/simulasi, kebijakan deduplikasi multi-attempt, laporan individu anti-bocor kunci, analisis butir soal (`N < 15` guard), ekspor resmi `.xlsx`/`.csv`/`.pdf` & `@media print`, editor aturan XP/lencana Admin, monitoring penggunaan Admin, serta animasi selebrasi penyelesaian dunia.
9. **Persiapan Operasional Sekolah & Deployment (Berikutnya)**: Aktivasi `GEMINI_API_KEY`, Firebase Storage bucket, uji E2E browser guru & siswa dengan login Google nyata, penjadwalan PSAS otomatis berbasis kalender, dan deployment Google Cloud Run dengan persetujuan pemilik proyek.
